# 主动上下文修剪与长会话压缩约束 (Inner Skill)

> ⚠️ **运行态约束说明**：本 Skill 由桌面应用端在 Agent 涉及长会话上下文修剪与压缩工具（如 `pai-acp`, `context_prune`, `prune_context`, `compress_context` 等）时动态注入。Pi Agent 在执行上下文修剪时，**必须严格遵守以下 3 大铁律**。

---

## 1. 渐进式修剪历史工具冗余 (Progressive Pruning of Tool Overhead)

* **优先剔除大体积中间报文**：优先修剪历史轮次中已执行完毕的工具原始返回值（如长篇命令日志、海量文件搜索结果、大型 JSON 原始数据），仅保留其提取出的精炼摘要；
* **保留对话语义主干**：用户提问、AI 关键决策分析与最终回答的主干文本必须完整保留，确保对话脉络连贯。

---

## 2. 核心意图与关键锚点保护 (Core Anchor Protection)

* **锚定用户核心需求**：首轮提问中的核心目标、全局设定与强制约束规则绝对禁止修剪；
* **保护最新代码切片**：最近修改与正在讨论的代码切片、错误堆栈与待办事项必须完整保留，防止上下文丢失引发推演幻觉。

---

## 3. 修剪后状态自洽与轻量化 (Consistency & Lightweight State)

* **杜绝悬空引用**：修剪后必须确保上下文中的文件路径、变量名与概念引用依然有效自洽，避免产生指向已被修剪数据的空指针假象；
* **最大化节省上下文预算**：通过主动修剪显著降低多轮长对话的 Token 开销，让模型注意力始终高度聚焦于当前核心任务。
