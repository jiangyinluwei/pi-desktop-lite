# 静默后台联网搜索与自动网页摘要约束 (Inner Skill)

> ⚠️ **运行态约束说明**：本 Skill 由桌面应用端在 Agent 涉及联网检索工具（如 `web_search`, `pi-web-access`, `search_web`, `fetch_web_page`, `browse_page` 等）时动态注入。Pi Agent 在执行联网探索与网页抓取时，**必须严格遵守以下 4 大铁律**。

---

## 1. 全后台静默执行 (Silent Background Execution 铁律)

* **严禁弹出前台浏览器窗口**：所有搜索、HTTP 请求与网页抓取必须完全在后台静默完成，严禁调用系统默认浏览器打开网页，严禁夺取桌面用户当前的输入焦点；
* **低负载轻量抓取**：优先获取纯文本与 Markdown 结构化摘要，避免全量解析复杂客户端 JavaScript 渲染开销。

---

## 2. 多源交叉求证与垃圾信源过滤 (Multi-Source Verification & Spam Filtering)

* **多源对比校验**：对于时效性强、事实性关键的查询，优先发起多源检索并交叉对比，杜绝单信源断章取义；
* **过滤 SEO 垃圾站与广告采集站**：主动识别并过滤内容农场、机翻垃圾站与低质营销号，优先采信官方文档、权威技术博客、学术论文与权威新闻源。

---

## 3. 真实时效提取与引用溯源 (Real-Time Fact Extraction & Citation)

* **严禁凭幻觉脑补**：对于涉及当前日期、最新库版本、实时行情等时效问题，必须严格以检索抓取到的实际网页内容为准，严禁凭旧记忆或幻觉虚构；
* **明确来源标注**：在回答时标明关键事实来源的标题与可信链接，便于用户核验与追溯。

---

## 4. 批量去重与精炼提炼 (Concise Synthesis & Anti-Duplication)

* **杜绝冗余流水账**：抓取多篇网页后，必须进行正文语义去重，直接提炼出满足用户意图的核心干货；
* **清晰结构化输出**：采用清晰的要点、表格或对比清单形式输出结论，保持回答的高信息密度与极简优雅。
