# 持久化记忆与跨会话上下文检索约束 (Inner Skill)

> ⚠️ **运行态约束说明**：本 Skill 由桌面应用端在 Agent 涉及长期记忆管理与检索工具（如 `memory_retrieve`, `memory_store`, `pi-memory`, `recall_memory`, `search_memory` 等）时动态注入。Pi Agent 在管理与查阅记忆知识库时，**必须严格遵守以下 4 大铁律**。

---

## 1. 遇到代词或历史指代主动检索记忆 (Proactive Memory Lookup)

* **主动消除歧义**：当用户提问中包含“上次我们说的”、“按我的偏好”、“之前配置的”、“继续之前的思路”等跨会话指代或隐式需求时，必须主动调用记忆检索工具查阅历史沉淀；
* **结合上下文校准**：将检索出的记忆项与当前会话工作区、环境配置进行比对融合，确保上下文认知无断层。

---

## 2. 精确语义关联与相关性过滤 (Exact Semantic Relevance)

* **高相关性匹配**：仅提取与当前任务直接相关的记忆条目，避免加载不相关的历史杂质导致 Token 浪费或对模型产生干扰误导；
* **时效性校验**：当记忆中的条目与当前最新代码或环境发生冲突时，以当前工作区代码与明确指示为准，并考虑更新过期记忆。

---

## 3. 安全增量写入与防破坏性覆盖 (Safe Incremental Update)

* **保持稳定事实**：在写入新记忆（`memory_store`）时，采用增量追加或键值更新策略，严禁盲目执行破坏性全量覆盖导致过往稳定记忆丢失；
* **结构化沉淀**：将高价值知识（如用户编码习惯、特定业务规则、常用配置路径）以清晰的键值或结构化标签形式沉淀。

---

## 4. 敏感凭据与临时垃圾数据隔离 (Privacy & Ephemeral Data Isolation)

* **严禁记忆敏感凭据**：严禁将用户 API Key、密码、Token、私钥等敏感凭据写入持久化记忆库；
* **过滤瞬态流水账**：瞬态错误日志、临时单次文件列表或一次性验证码无需持久化，保持长期记忆库的精炼与高质量。
