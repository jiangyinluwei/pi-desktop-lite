# 多格式文档与目录深度遍历解析约束 (Inner Skill)

> ⚠️ **运行态约束说明**：本 Skill 由桌面应用端在 Agent 涉及目录分析或读取多格式文档/图像时动态注入。Pi Agent 在规划与调用文件探索、文档读取或 OCR 相关工具时，**必须严格遵守以下 4 大铁律**。

---

## 1. 主动目录深度遍历 (Proactive Folder Traversal & Inspection)

* **严禁止步于文件名**：当接收到本地目录路径或探索项目文件结构时，必须主动递归/遍历内部目标文件，严禁仅打印文件名列表或仅凭文件标题做表面推测；
* **全面真实检索**：对目录内所有相关的业务文档与资料，必须逐一深入提取实际文本内容进行分析。

---

## 2. 禁止二进制裸读 (Anti-Raw-Binary Read 铁律)

* **严禁纯文本读取二进制格式**：严禁对 `.docx`, `.doc`, `.pdf`, `.pptx`, `.xlsx`, `.png`, `.jpg`, `.jpeg`, `.webp` 等非纯文本/二进制格式使用 `cat`、`type` 或普通纯文本文件读取工具；
* **避免乱码与上下文污染**：用普通文本工具读取二进制数据会导致大量乱码字符或空输出，严重破坏上下文并导致推演失败。

---

## 3. 自动调度专用文档解析与 OCR 组件 (Mandatory Specialized Tool & OCR Invocation)

* **Word / Docx 解析**：遇到 `.docx` / `.doc` 文件时，必须自动调用可用的专用 Word 解析组件或工具（如 `deword`、`pi-docparser` 或对应解析脚本）提取段落、表格与标题；
* **PDF 与图像 OCR 提取**：遇到 `.pdf` 或图像（`.png`, `.jpg`, `.webp`）时，必须自动调用 `pi-ocr`、多模态视觉工具或 OCR 提取组件识别正文；
* **表格与结构化数据**：遇到 `.xlsx` / `.xls` 等电子表格时，自动调用结构化数据提取工具进行单元格解析。

---

## 4. 真实内容全量综合汇总 (Batch Content Synthesis)

* 批量提取目标目录下全部文档的正文与结构后，必须结合真实内容进行事实准确的提炼、归纳与回答，杜绝空洞泛化的推论。
