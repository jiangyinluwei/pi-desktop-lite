# 多智能体并行与子任务协作调度约束 (Inner Skill)

> ⚠️ **运行态约束说明**：本 Skill 由桌面应用端在 Agent 涉及多智能体协同调度（如 `subagent`, `spawn_agent`, `parallel_tasks`, `delegate_task` 等工具）时动态注入。Pi Agent 在规划与调用多 Agent 协作工具时，**必须严格遵守以下 4 大铁律**。

---

## 1. 明确子任务边界与独立上下文 (Clear Subtask Boundaries & Scope)

* **独立自治与单向职责**：每个分发出去的子 Agent 必须拥有清晰独立的目标、边界范围与输入参数，严禁下发模糊、重叠或相互依赖导致死锁的子任务；
* **按需最小上下文注入**：向子 Agent 传递上下文时仅提供完成该子任务必需的背景与约束，杜绝无差别塞入无关历史对话导致 Token 损耗与注意力偏移。

---

## 2. 非阻塞并发派发 (Parallel Dispatch Without Blocking)

* **无序依赖并行加速**：对相互无数据依赖的独立子任务（如并发分析多个不同文件、并行检索多个独立关键词），必须尽量采用并发/并行调度，严禁单线程串行等待；
* **动态负载控制**：合理控制并发子 Agent 数量，避免瞬间创建过多进程耗尽系统资源。

---

## 3. 严格超时与异常隔离 (Strict Timeout & Fault Isolation)

* **异常兜底与状态保护**：任何单个子 Agent 的执行失败、报错或超时，不得直接导致主调度链路崩溃；主 Agent 必须捕获异常并实施降级自愈或重试；
* **生命周期受控**：主任务终止或发生 Abort 时，必须级联终止所有子 Agent 进程，杜绝后台残留孤儿进程。

---

## 4. 主端汇聚清洗与事实整合 (Synthesis & Result Cleanup)

* **严禁裸抛原始报文**：主 Agent 收到所有子 Agent 的执行结果后，必须统一进行信息去重、结构化提取与深度清洗；
* **综合归纳统一输出**：必须将各个子任务的真实分析结论融合为逻辑连贯、事实准确的最终答复，呈现给用户。
